# Ledge Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Turn the Ledge skeleton into a shared, optimized map system with plugin web viewing and Fabric full-screen map tools.

**Architecture:** Keep stable map models, tile addressing, bounded image processing, and persistence contracts in `common`. Keep Paper/GLAP world access and localhost HTTP serving in `glap1`; keep Fabric input, rendering, player marker preference, map tools, and screenshot export in `fabric`. Exchange live tile updates through a versioned, size-limited plugin message protocol.

**Tech Stack:** Java 25, Gradle 9.8.2 wrapper, Minecraft 26.3, Paper/GLAP1 API, Fabric Loader/API, Java AWT/ImageIO where supported.

**Spec:** `docs/superpowers/specs/2026-11-04-ledge-map-design.md`

## Global Constraints

- Java release and toolchain remain 25.
- Minecraft target remains 26.3.
- Web map is GLAP1 plugin-only; full-screen map and screenshots are Fabric-only.
- Default web bind is loopback; external bind requires explicit config.
- Do not perform world access or blocking disk/network work on the game thread.
- Tile and screenshot memory/size/concurrency must be bounded.
- Do not include Xaero ARR code; use Chunky's public API as an optional runtime integration.
- Player-marker visibility is selected locally by each Fabric client.
- No chat, game time/date, or share-link features.
- Automated tests are omitted unless the user asks for them; use compile/package verification for implementation checks.

## Review Focus

- Missing/corrupt/out-of-range tiles must result in a safe placeholder or controlled error, not an unbounded allocation.
- Negative world coordinates and dimension identifiers must map to stable tile keys.
- Rapid chunk edits must coalesce without stale tile writes overwriting newer output.
- Plugin-message payloads must be versioned and bounded; malformed payloads must be discarded.
- Screenshot selections with reversed corners, empty bounds, or excessive pixel area must be normalized or rejected safely.

## Planned Files

- `common/src/main/java/dev/ledge/common/**`: immutable map config, dimension/tile keys, renderer and layer models, tile cache/store contracts, overlay data, and bounded image utilities.
- `glap1/src/main/java/dev/ledge/glap1/**`: config loading, server tile scheduler/world snapshots, Chunky discovery/adapter, plugin-message protocol, localhost HTTP server and static map UI.
- `glap1/src/main/resources/**`: plugin defaults and web assets.
- `fabric/src/main/java/dev/ledge/fabric/**`: map key binding, map screen/view state, tile receiver/cache, coordinate panel, tool menu/forms, local player-marker setting, and screenshot writer.
- `fabric/src/main/resources/**`: default client config and UI resources.
- `README.md`: install, config, commands, and limitations.

## Task 1: Shared map model and tile primitives

**Deliverable:** Platform-independent dimension/world configuration, renderer/resolution identifiers, tile keys, dirty-region and overlay models, and bounded tile image/store APIs. Preserve `MapCoordinate` compatibility.

**Verification:** `./gradlew :common:jar` compiles and packages the common module.

## Task 2: GLAP tile rendering, Chunky integration, and web map

**Deliverable:** Plugin configuration with per-world renderer/resolution, tile storage, coalesced rate-limited render queue, optional Chunky API adapter, bounded loopback HTTP server, and responsive web viewer showing dimensions, 2D/3D, markers, overlays, and live tile changes.

**Verification:** `./gradlew :glap1:jar` compiles and packages the server plugin.

## Task 3: Fabric full-screen map and live map protocol

**Deliverable:** Configurable Z key, versioned bounded plugin-message tile receiver, pan/zoom, dimensions, 2D/3D, renderer/resolution view settings, live updates, local player-marker toggle with skin-face markers, and hovered XYZ panel with close button.

**Verification:** `./gradlew :fabric:jar` compiles and packages the Fabric mod.

## Task 4: Fabric map tools and print workflow

**Deliverable:** Right-click marker/fill/outline tools with validated name/hex input and persistence, drag-selected print bounds, preview/confirmation, safe PNG output under screenshots, and size caps.

**Verification:** `./gradlew :fabric:jar` compiles and packages the Fabric mod.

## Task 5: Integration and documentation

**Deliverable:** Compatible defaults, install/config documentation, all artifacts built, and a file-by-file requirement review.

**Verification:** `./gradlew :common:jar :glap1:jar :fabric:jar` exits successfully; inspect JAR contents and `git diff`.
